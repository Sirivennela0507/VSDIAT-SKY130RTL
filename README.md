VSDIAT SKY130 RTL Design and Physical Design
📌 Project Overview

This repository documents my learning and hands-on work in RTL Design, Static Timing Analysis (STA), and Physical Design using the SKY130 technology as part of the VSDIAT workshop.

The project includes RTL design workshop materials, timing analysis across multiple corners, and physical design-related work using open-source VLSI design tools.

🛠️ Topics Covered
RTL design using Verilog HDL
RTL synthesis concepts and digital design fundamentals
Static Timing Analysis (STA)
Multi-corner timing analysis
SKY130 technology and open-source Process Design Kit (PDK)
Physical design concepts and implementation workflows
Open-source VLSI design tools

🎯 Project Objectives
Understand the digital design flow from RTL development to implementation.
Explore RTL synthesis and timing analysis concepts.
Analyze timing behavior across different operating corners.
Gain practical exposure to open-source VLSI design tools.
Document workshop activities, implementation steps, and results.

💻 Tools and Technologies
Technology: SKY130
Hardware Description Language: Verilog HDL
EDA Tools: Yosys, OpenSTA, OpenROAD, and other open-source EDA utilities, as applicable to the workflow
Design Domain: RTL Design, Static Timing Analysis, and Physical Design
