VSDIAT SKY130 RTL Design and Physical Design
📌 Project Overview

This repository documents my work and learning in RTL Design, Static Timing Analysis (STA), and Physical Design using the SKY130 technology as part of the VSDIAT workshop.

The project brings together RTL design workshop materials, timing analysis across multiple corners, and physical design-related work using open-source VLSI design tools.

📂 Repository Structure

The repository contains the following main directories:

_RTL_Design_Workshop/ — RTL design and workshop-related materials.
STA_all_corners/ — Static Timing Analysis (STA) work organized around multiple timing corners.
physicaldesign/ — Physical design-related files and implementation work.
🛠️ Topics Covered
RTL design using Verilog HDL
RTL design and synthesis concepts
Static Timing Analysis (STA)
Multi-corner timing analysis
SKY130 technology and open-source VLSI design workflows
Physical design concepts and implementation
🎯 Project Objectives
Understand the digital design flow from RTL development to implementation.
Explore synthesis and timing analysis concepts.
Study timing behavior across different operating corners.
Gain practical exposure to open-source VLSI design tools.
Document project activities, implementation steps, and results.
💻 Tools and Technology
Technology: SKY130
Hardware Description Language: Verilog HDL
EDA tools: Depending on the workflow, tools such as Yosys, OpenSTA, OpenROAD, and other open-source EDA utilities may be used.
